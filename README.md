# Iris Flower Classification Project 🌸

A complete Machine Learning project for Iris flower classification using SVM and KNN algorithms with a Flask web interface.

## 📋 Project Overview
This project demonstrates end-to-end ML workflow including:
- Data Collection and Analysis (Reena)
- Data Preprocessing & Visualization(Sejal)
- Feature Selection(Sejal)
- Model Training (SVM & KNN)(Harshita)
- Hyperparameter Tuning(Reena)
- Model Evaluation & Comparison(Harshita)
- Web Interface with Flask(Reena)

## 🚀 Features
- Interactive web interface with beautiful UI
- Real-time predictions using both SVM and KNN models
- Model comparison functionality
- Probability visualization with charts
- Responsive design

## 📊 Model Performance
- **SVM Accuracy**: ~97-100%
- **KNN Accuracy**: ~95-100%
- **Cross-validation Score**: ~96-98%

## 🛠️ Tech Stack
- **Backend**: Python, Flask
- **ML Libraries**: scikit-learn, pandas, numpy
- **Frontend**: HTML, CSS, JavaScript, Bootstrap
- **Visualization**: Matplotlib, Seaborn, Plotly
