Project Overview

This project demonstrates a complete end-to-end Machine Learning workflow for classifying Iris flower species using two different algorithms: Support Vector Machine (SVM) and K-Nearest Neighbors (KNN).

The Iris dataset is one of the most famous datasets in machine learning, containing measurements of 150 Iris flowers from three species: Setosa, Versicolor, and Virginica.

Model Details

SVM (Support Vector Machine)

  • Best Parameters: C=10, kernel='rbf', gamma='scale'
  • Accuracy: 97-100%
  • Cross-validation Score: 96-98%
  • Strengths: Works well with clear margins, memory efficient

KNN (K-Nearest Neighbors)

  • Best Parameters: metric = euclidean, n_neighbors=11, weights='distance'
  • Accuracy: 95-100%
  • Cross-validation Score: 95-97%
  • Strengths: Simple, effective for smaller datasets
